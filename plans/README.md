## Findings considered and rejected

- **Lua-only bridge** (`w3.use("modUnicornCore")` inside our TW3SE layer):
  rejected — forces the release package to ship production Lua and breaks the
  "release works without TW3SE" rule (research §4.3).
- **Direct `CUnicorn` symbols inside `modMCME_AutonomousRomance`**: rejected —
  WitcherScript binds symbols at compile time; without `modUnicornCore` the base
  mod would fail to compile for non-Unicorn users (research §4.1).
- **Wrap Unicorn's own methods from the bridge** (except the documented
  `RegisterPacks` extension point): rejected — `@wrapMethod` shadowing between
  unmerged mods silently drops wrappers (AGENTS.md §3.1).
- **Reusing `HardStage`/teleport pipeline for Unicorn scenes**: deferred —
  Unicorn positions actors itself; reuse only if F0 live tests show it is needed
  (research R6).
