; Zgoda (consent) dziala przez POLLING vanilla akcji "SwordSheathe":

; Polling to pasywne GetAction/IsPressed w petli zgody - mod NIE rejestruje

; playerInput.ws) pozostaje nietkniety i sheathing na C dziala (W3-TIK-021 par.9).
;
; Historia: poprzednie wersje tego pliku podpinaly zgode pod C liniami
; w formacie krotki (tuple) - "IK_C" z dwiema akcjami w jednym bindingu
; (SwordSheathe + MCM_AR_Consent). Ta skladnia jest NIEPRAWIDLOWA: gra
; normalizuje ja do pierwszej akcji, wiec consent nigdy nie byl realnie
; podpiety, a fragment jedynie nadpisywal vanilla binding. Linie usuniete.
;
; Dedytkowany klawisz zgody (opcjonalnie, recznie) - README, sekcja
; "Input Bindings (Consent Key)": akcja MCM_AR_Consent musi byc
; zadeklarowana w bin\config\r4game\legacy\base\input_qwerty.ini, wpisana
; w Documents\The Witcher 3\input.settings (ten sam kontekst) i opcjonalnie
; dopisana do bin\config\r4game\user_config_matrix\pc\input.xml.
; Przykladowa linia do przeklejenia (klawisz Z - wolny w vanilla):
;   IK_Z=(Action=MCM_AR_Consent)
; Nie wysylamy domyslnego klawisza w tym fragmencie - kazdy dedykowany
; binding wymaga recznej deklaracji, a Z moze byc juz zajety przez inne mody.
