; MCME Autonomous Romance - input.settings fragment (Settings Updater / W3MM)
;
; This fragment INTENTIONALLY contains no bindings (zero "IK_" lines) and
; does not touch the IK_C key in any context.
;
; Consent works through POLLING of the vanilla "SwordSheathe" action:
;   - C behaves like vanilla (sheathe/undraw the sword),
;   - while a consent prompt is on screen, holding C for ~1 s or tapping
;     C twice accepts the romance.
; Polling is a passive GetAction/IsPressed read inside the consent loop -
; the mod does NOT register a listener on the vanilla action, so the game's
; native handler (OnCommSheatheAny, playerInput.ws) stays untouched and
; sheathing on C keeps working (W3-TIK-021 par.9).
;
; History: earlier versions of this file bound consent to C via tuple
; syntax - "IK_C" carrying two actions in one binding (SwordSheathe +
; MCM_AR_Consent). That syntax is INVALID: the game normalizes it to the
; first action only, so consent was never really bound and the fragment
; merely overwrote the vanilla binding. Lines removed.
;
; Dedicated consent key (optional, manual) - see README, section
; "Input Bindings (Consent Key)" or consent-key.snippet.txt: the
; MCM_AR_Consent action must be declared in
; bin\config\r4game\legacy\base\input_qwerty.ini, bound in
; Documents\The Witcher 3\input.settings (same context), and optionally
; added to bin\config\r4game\user_config_matrix\pc\input.xml.
; Ready-made example line (key Z - free in vanilla):
;   IK_Z=(Action=MCM_AR_Consent)
; We ship no default key in this fragment - every dedicated binding needs
; manual declaration, and Z may already be taken by other mods.
;
; Merging this comment-only fragment is safe: Settings Updater / W3MM
; append these lines to Documents\The Witcher 3\input.settings, and the
; game ignores entries starting with ';'.
